# Italiano 1.0 per Colobot Gold 0.2.2-alpha Windows 64 bit

[Scarica lo ZIP stabile](../dist/colobot-0.2.2-alpha-win64-italiano-1.0.zip).
Apri il file su GitHub e premi **Download raw file**. Il file `.sha256` accanto
allo ZIP consente di verificarne l’integrità.

1. Chiudi il gioco.
2. Estrai tutto nella cartella che contiene `colobot.exe` e `data`.
3. Accetta la sostituzione dei file della precedente traduzione, se presente.
4. Avvia `Avvia-Italiano.cmd` e mantieni **French** nelle impostazioni.

La 1.0 è il pacchetto comunitario confermato dall’utente. Non sostituisce
eseguibili, DLL, font o i cataloghi originali. Riutilizza i salvataggi delle
anteprime e della RC1 in `%LOCALAPPDATA%\ColobotItalianPreview-0.1`.
L’avvio normale con `colobot.exe` e i suoi salvataggi restano separati.

Per rimuoverla elimina `Avvia-Italiano.cmd`, `LEGGIMI-ITALIANO.txt` e
`colobot-it-preview`; puoi conservare la cartella dei salvataggi.

Questo ZIP è destinato alla **0.2.2-alpha**, contiene 5.172 voci nei cataloghi
e resta invariato. I sorgenti in `main` sono ora destinati a `dev`: per
ricostruire esattamente la 1.0 usare il tag
[`italiano-v1.0`](https://github.com/danielemorelli92/colobot_it/tree/italiano-v1.0)
o i sorgenti inclusi nello ZIP. Le anteprime rimosse dal ramo principale sono
ancora disponibili nella cronologia e nello stesso tag.

Le stringhe dei programmi e gli identificatori tecnici restano invariati;
i commenti sono tradotti. La documentazione originale del robot disegnatore
contiene solo `TODO`; la pagina italiana segnala che non è disponibile.
I metadati non gettext di AltTextures e le mod esterne non sono inclusi.

Distribuita sotto GPL v3 o successiva. Non è una release ufficiale di Colobot.
